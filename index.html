01

แง่ที่ 1 · Higgsfield

การสร้างรูปด้วย AI

โจทย์: ภาพประกอบเรื่อง "นักเรียนกับ AI ผู้ช่วยเรียนรู้ตอนกลางคืน" — พรอมป์แรกสั้นเกินไป ทำให้โมเดลต้องเดาทุกอย่างเอง

  • ภาพออกมาเป็นห้องเรียนทั่วไป อยากได้กลางคืน คนเดียว บรรยากาศเงียบ ๆ ต้องระบุอะไร? → เวลา/แสง (กลางคืน โคมไฟอุ่น) จำนวนคน (1 คน) และอารมณ์ภาพ (เงียบ โฟกัส)
  • อยากให้เห็นชัดว่า AI ช่วยเรียน และกันภาพเสียยังไง? → เพิ่มองค์ประกอบโฮโลแกรมเหนือแล็ปท็อป เขียนเป็นภาษาอังกฤษที่มีคำศัพท์ภาพแม่นกว่า และปิดท้ายด้วย no text, no watermark
พรอมป์แรก · zero-shot

นักเรียนกำลังเรียนหนังสือด้วย AI

พรอมป์ใหม่ · few-shot (จากการถาม-ตอบ)

สะท้อนที่ได้: พรอมป์สั้นให้ความหมายแต่ไม่ให้ภาพ — โครงสร้าง subject → scene → lighting → composition → constraints คือสิ่งที่ทำให้คุมผลลัพธ์ได้เกือบทั้งหมด และควรทดสอบด้วยความละเอียดต่ำก่อนจ่ายเครดิตใบ้ ๆ

02

แง่ที่ 2 · Desmos

กราฟอธิบายความสัมพันธ์ทางคณิตศาสตร์

โจทย์: สื่อสาร "เส้นโค้งการลืม" ของนักเรียนตามทฤษฎี Ebbinghaus ให้เป็นกราฟที่เลื่อนดูค่าได้จริง

  • อยากสื่อการลืมบทเรียนตามทฤษฎี Ebbinghaus ต้องใช้สมการอะไร? → R(t) = A·e^(−t/S) โดย A คือความจำตอนเรียนจบ และ S คือความแข็งแรงของความจำเป็นวัน — ทบทวนมาก S ใหญ่ กราฟลดช้า
  • อยากให้เพื่อนเลื่อนค่าดูเองได้ และชี้จุดวิกฤตยังไง? → พิมพ์ A=100 และ S=7 ก่อนเพื่อให้ Desmos สร้าง slider อัตโนมัติ แล้วเพิ่มเส้น y=50 — จุดตัดคือจำนวนวันก่อนความจำหลุดครึ่งหนึ่ง
พรอมป์แรก · zero-shot

สร้างกราฟ y = sin x

พรอมป์ใหม่ · few-shot (จากการถาม-ตอบ)

สร้างกราฟเส้นโค้งการลืม R(t) = A·e^(−t/S) กำหนด slider A=100 (ความจำเริ่มต้น %) และ slider S=7 (ความแข็งแรงของความจำ วัน) เพิ่มเส้น y=50 เป็นเส้นวิกฤตการลืม ให้นักเรียนเลื่อน S ดูว่าการทบทวนทำให้กราฟลดช้าลงเพียงใด

สะท้อนที่ได้: ความต่างไม่ได้อยู่ที่กราฟสวยขึ้น แต่อยู่ที่เป้าหมายของกราฟ — พอทำ A และ S เป็น slider กราฟนิ่งก็กลายเป็นเครื่องมือสำรวจที่ผู้เรียนได้ "เล่น" กับคณิตศาสตร์จริง

แง่ที่ 3 · Mermaid

การสร้าง Diagrams จากโค้ด

โจทย์: ไดอะแกรมสรุป "วงจรพัฒนาพรอมป์" ที่เป็นแกนของการบ้านทั้งชิ้น — พรอมป์แรกได้กล่องสี่ใบที่ใครก็เขียนได้

  • อยากให้เห็นชัดว่ามี 2 รอบ ต้องใช้ syntax อะไร? → ใช้ subgraph ครอบแต่ละรอบพร้อมตั้งชื่อกลุ่ม เช่น "รอบที่ 1 · Zero-shot"
  • แยกสีตามช่วงได้ไหม และอะไรเชื่อมสองรอบ? → ใช้ classDef สี 3 ชุด (น้ำเงิน=รอบแรก ทอง=รอบสอง เขียว=กระบวนการ) และเพิ่มกล่อง "ถาม-ตอบเพื่อปรับ prompt" เป็นสะพานเชื่อม
พรอมป์แรก · zero-shot

เขียน mermaid diagram แสดงการพัฒนา prompt

พรอมป์ใหม่ · few-shot (จากการถาม-ตอบ)

สร้าง flowchart TD: subgraph รอบ 1 Zero-shot → กล่องถาม-ตอบเพื่อปรับ prompt → subgraph รอบ 2 Few-shot → จุดตัดสินใจ "ตรงกับเป้าหมายไหม" (ไม่ตรงวนกลับ) → สะท้อนการเรียนรู้ ใช้ classDef สี 3 ชุด ข้อความไทยทั้งหมด

สะท้อนที่ได้: ไดอะแกรมต้องการข้อความที่คมก่อน syntax — การรู้คำสั่งเฉพาะของเครื่องมือ (subgraph, classDef) คือ few-shot เชิงเทคนิคที่ทำให้คุมผลลัพธ์ได้ และสีไม่ใช่การตกแต่งแต่เป็นชั้นข้อมูล

แง่ที่ 4 · LaTeX (Tectonic/XeLaTeX)

การสร้างบทความจาก LaTeX

โจทย์: บทความสรุปบทเรียนสัปดาห์นี้ — พรอมป์แรกได้เทมเพลตอังกฤษว่างเปล่าที่ส่งงานจริงไม่ได้

  • อยากได้บทความภาษาไทย LaTeX ต้องตั้งค่ายังไง? → คอมไพล์ด้วย XeLaTeX ใช้ fontspec ตั้งฟอนต์ไทย (Thonburi) และเปิด XeTeXlinebreaklocale "th" เพื่อตัดคำไทยให้ถูกต้อง
  • อยากให้เนื้อหาลึกและเป็นระบบ ควรกำหนดอะไร? → กำหนดโครงเรื่อง: บทคัดย่อ → บทนำ → กรอบวิเคราะห์ (มีสมการ) → ตารางเปรียบเทียบ 6 แง่ → ข้อเสนอแนะ → บทสรุป พร้อมตารางแบบ booktabs
พรอมป์แรก · zero-shot

เขียนบทความเรื่อง prompt engineering ด้วย latex

พรอมป์ใหม่ · few-shot (จากการถาม-ตอบ)

เขียนบทความวิชาการภาษาไทยด้วย XeLaTeX + fontspec ฟอนต์ Thonburi + ตัดคำไทย ชื่อเรื่อง "พลังของ Prompt: จาก Zero-shot สู่ Few-shot" ผู้อ่าน: นักศึกษาวิศวคอม มีบทคัดย่อ สมการ Qn = Q0(1+α)^n ตาราง booktabs เทียบ 6 แง่ ข้อเสนอแนะ และบทสรุป

สะท้อนที่ได้: LaTeX มีกับดักภาษา — ไม่ระบุ engine และฟอนต์ ภาษาไทยก็พังทั้งไฟล์ การกำหนดโครงเรื่องล่วงหน้าในพรอมป์ยังเปลี่ยนผลลัพธ์จาก "เทมเพลต" ให้เป็น "บทความ" จริงอีกด้วย

แง่ที่ 5 · NotebookLM

สร้างสไลด์สรุปงานด้วย NotebookLM

โจทย์: สรุปสไลด์เรียน Week 4 "พลังของ Prompt" (42 หน้า) ให้นักศึกษาทบทวนได้ใน 5 นาที — คำสั่งสั้นได้กลับมาเป็นย่อหน้าข้อความ ไม่ใช่สไลด์

  • อยากได้สไลด์ให้นักศึกษาทบทวนก่อนสอบ ต้องกำหนดอะไร? → จำนวนหน้า (10) โครงเรื่องตามลำดับการสอน และรูปแบบหน้าละไม่เกิน 3 bullet
  • อยากเน้นคำศัพท์ที่อาจออกข้อสอบ ทำได้ไหม? → ได้ — เพิ่มเงื่อนไขให้คำสำคัญเป็นตัวหนา และหน้าสุดท้ายรวมคำศัพท์+ตัวย่อเป็นตาราง
พรอมป์แรก · zero-shot

สรุปไฟล์นี้เป็นสไลด์

พรอมป์ใหม่ · few-shot (จากการถาม-ตอบ)

คุณเป็นผู้ช่วยสอนรายวิชา GenAI 1 จงสรุปเอกสาร Week 4 เป็นสไลด์ทบทวน 10 หน้า ภาษาไทย โครง: นิยาม → AI เข้าใจภาษา → Zero/One/Few-shot → RGC → Priming+Chain of Thought → Prompt Inception → ตัวอย่างจริง → สรุป+ตารางคำศัพท์ หน้าละไม่เกิน 3 bullet คำสำคัญตัวหนา

สะท้อนที่ได้: เครื่องมือสรุปเอกสารมีค่าเริ่มต้นของมันเอง — ไม่ระบุรูปแบบผลลัพธ์ก็ได้ข้อความย่อ ไม่ใช่สื่อการสอน ส่วนทำซ้ำใน NotebookLM จริงได้ใน 5 นาทีตามขั้นตอนท้ายหน้านี้

แง่ที่ 6 · GitHub Pages

เขียนเว็บไซต์เพื่อฝากบน GitHub

โจทย์: เว็บรวมการบ้านที่อาจารย์เปิดดูได้ทันที — พรอมป์แรกได้หน้าเดียวเลื่อนยาว ไม่มีการนำทาง

  • อยากให้อาจารย์เลือกดูทีละแง่ได้ง่าย ต้องออกแบบนำทางยังไง? → เมนูบนแบบเลือกหมวดพร้อม anchor ตรงถึงแต่ละแง่ และใช้ธีมเดียวกันทั้งเว็บให้งาน 6 แง่อ่านเป็นชิ้นเดียว
  • ขึ้น GitHub Pages ยังไงให้เป็นลิงก์ที่เปิดได้เลย? → สร้าง repo genai-prompt-lab push ขึ้น main แล้วเปิด Pages ชี้ที่ root ของ branch — ได้ลิงก์ fiezdev.github.io/genai-prompt-lab
พรอมป์แรก · zero-shot

ทำเว็บไซต์สรุปงานการบ้าน

พรอมป์ใหม่ · few-shot (จากการถาม-ตอบ)

สร้างเว็บ "พลังของ Prompt" บนฐานธีม ai-arai-dee (Astro + parallax): เมนูบนเลือก 6 แง่ แต่ละแง่มีพรอมป์ก่อน-หลัง ผลงานจริงฝังในหน้า บทสนทนาถาม-ตอบ และการ์ดสะท้อนการเรียนรู้ responsive ทั้งมือถือและจอคอม เผยแพร่ด้วย GitHub Pages

สะท้อนที่ได้: เว็บคือสื่อ ไม่ใช่เอกสาร — พรอมป์แรกคิดถึงเนื้อหาแต่ลืมผู้อ่านและการนำทาง พอทำครบ 6 แง่ก็เห็นแบบแผนเดียวกันหมด: zero-shot ได้ของทั่วไป few-shot ได้ของของเรา

วิธีทำงานของการบ้านทั้งชิ้น

วงจรเดียวกันทั้ง 6 แง่

1

เขียนพรอมป์แรก (zero-shot)

สั่งสั้นที่สุดแบบที่คนทั่วไปพิมพ์กันจริง ๆ แล้วบันทึกผลลัพธ์ไว้เป็น "รอบแรก" ไม่แก้ ไม่เพิ่ม

2

ดูผล แล้วถามต่อ

จดจุดอ่อนของผลแรกเป็นคำถาม เช่น ใครอ่าน? รูปแบบไหน? ข้อจำกัดอะไร? แล้วคุยกับ AI ทีละข้อจนรู้ว่าต้องระบุอะไร

3

สังเคราะห์พรอมป์ใหม่ (few-shot)

รวมบทบาท + บริบท + รูปแบบผลลัพธ์ + ข้อจำกัด เป็นพรอมป์รอบสอง แล้วเทียบผลก่อน-หลังพร้อมสะท้อนว่าอะไรเปลี่ยน

ทุกแง่จบด้วยบทเรียนเดียวกัน: พรอมป์ที่ดีขึ้น ได้มาจากการถาม ไม่ใช่การเดา

ชุดส่งงานฉบับเต็มและผลงานจริงทั้งหมดอยู่ในลิงก์ด้านล่าง — เปิดดูได้ทันที ทุกไฟล์ทำจากเครื่องมือจริงทั้งสิ้น
