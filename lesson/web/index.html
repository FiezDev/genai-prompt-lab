แง่ที่ 6 · GitHub Pages

เขียนเว็บไซต์เพื่อฝากบน GitHub

โจทย์: เว็บรวมการบ้านที่อาจารย์เปิดดูได้ทันที — พรอมป์แรกได้หน้าเดียวเลื่อนยาว ผู้ตรวจต้องเลื่อนหาแง่ที่ต้องการเอง

เว็บที่กำลังอ่านอยู่นี้คือผลลัพธ์ของแง่ที่ 6 — และเป็นโบนัสที่รวมงานแง่ 1–5 ไว้ครบ

รอบที่ 1

พรอมป์แรก (zero-shot) และผลลัพธ์

พรอมป์แรก · zero-shot

ทำเว็บไซต์สรุปงานการบ้าน

ปรับพรอมป์ด้วยการถาม

ถาม–ตอบ เพื่อดึงรายละเอียดที่ควรระบุ

1

อยากให้อาจารย์เลือกดูทีละแง่ได้ง่าย ๆ ต้องออกแบบนำทางยังไง?

AI: เมนูบนแบบเลือกหมวด แต่ละแง่เปิดหน้าของตัวเอง (หน้าละบทเรียน) — แชร์ลิงก์ตรงถึงแต่ละแง่ได้ทันที

2

อยากได้ธีมที่ต่อเนื่องกับงานและคุณภาพสูงขึ้นทำยังไง?

AI: ยกเว็บ ai-arai-dee ทั้งธีมมาเป็นฐาน — parallax วิดีโอ ภาพเบลอเคลื่อนไหว และระบบ design token เดิม แล้วสร้างหน้าบทเรียนด้วยส่วนประกอบชุดเดียวกัน

3

ขึ้น GitHub Pages ยังไงให้เป็นลิงก์ที่เปิดได้เลย?

AI: สร้าง repo genai-prompt-lab push ขึ้น main แล้วเปิด Pages ชี้ที่ root ของ branch — ได้ลิงก์ fiezdev.github.io/genai-prompt-lab

รอบที่ 2

พรอมป์ใหม่ (few-shot) และผลลัพธ์

พรอมป์ใหม่ · few-shot (สังเคราะห์จากบทสนทนา)

ใช้เว็บ "ใช้ AI ทำอะไรดี" (ai-arai-dee: Astro + React + framer-motion parallax) เป็นฐาน: หน้าหลักคงเดิม เพิ่มเมนูบน 6 บทเรียน แต่ละบทเรียนเปิดหน้าของตัวเอง บรรจุพรอมป์ก่อน-หลัง ผลงานจริง บทสนทนาถาม-ตอบ และการสะท้อนการเรียนรู้ คุณภาพเทียบเท่าหน้าหลัก เผยแพร่ด้วย GitHub Pages

ผลลัพธ์ใหม่ · few-shot

หน้าหลักสไตล์ ai-arai-dee + เมนู 6 บทเรียน แต่ละแง่มีหน้าของตัวเองพร้อมผลงานจริง ธีมเดียวกันทั้งเว็บ งาน 6 แง่อ่านเป็นชิ้นเดียว — ตรงเงื่อนไขโบนัสพอดี

สะท้อนการเรียนรู้

เว็บคือสื่อ ไม่ใช่เอกสาร — พรอมป์แรกคิดถึงเนื้อหาแต่ลืมผู้อ่านและการนำทาง พอทำครบ 6 แง่ก็เห็นแบบแผนเดียวกันหมด: zero-shot ได้ของทั่วไป few-shot ได้ของของเรา

ผลลัพธ์แรก · zero-shot

หน้ายาวเดียว หลงทาง ไม่มีการนำทาง

ผลลัพธ์ใหม่ · few-shot

หน้าหลักสไตล์ ai-arai-dee + เมนู 6 บทเรียน แต่ละแง่มีหน้าของตัวเองพร้อมผลงานจริง ธีมเดียวกันทั้งเว็บ งาน 6 แง่อ่านเป็นชิ้นเดียว — ตรงเงื่อนไขโบนัสพอดี
